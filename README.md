# BEYOND - SKILLORA AI
1. Технологический стек
Frontend — пользовательский интерфейс
HTML5 — структура веб-приложения: главная страница, личные кабинеты, задания, курсы и другие разделы.

CSS3 — оформление интерфейса, цветовая схема, адаптивная компоновка и визуальные элементы.

JavaScript (Vanilla JS) — интерактивность, переключение разделов, обработка действий пользователей, работа с заданиями и обновление отображаемых данных.

Приложение реализовано в HTML-файле и не требует установки React, Vue или других frontend-фреймворков.
Хранение данных
LocalStorage — локальное хранение демонстрационных данных непосредственно в браузере.

В демонстрационном режиме приложение может работать без подключения внешней базы данных. Данные этого режима не синхронизируются между устройствами.

Supabase — предусмотренная в коде серверная интеграция для работы с пользовательскими данными, авторизацией и заданиями.

PostgreSQL — база данных, используемая Supabase для серверного хранения информации.
Искусственный интеллект
В коде предусмотрена интеграция с языковой моделью для проверки решений студентов.

ИИ-компонент предназначен для анализа выполненных заданий по пяти критериям:
1. Анализ и логика.
2. Структура ответа.
3. Аргументация.
4. Практическая применимость.
5. Креативность.
Результатом проверки должны быть оценки, обратная связь и рекомендации по улучшению работы.

В исходном коде предусмотрены обращения к window.claude и к серверной функции Supabase grade. Для их работы требуется соответствующее окружение или настроенный сервер.
Коммуникационные технологии
WebRTC — технология для видеосвязи и обмена медиаданными в реальном времени.

В проекте предусмотрены онлайн-комнаты, однако для полноценной связи между пользователями требуется работающая инфраструктура установления соединений.
2. Архитектура Skillora AI
Skillora AI построена как клиентское веб-приложение с возможностью подключения серверных сервисов.
Основные функциональные модули
Модуль студента. Предоставляет доступ к заданиям, образовательным материалам, результатам и персональному профилю навыков.

Модуль работодателя. Предназначен для размещения практических заданий и изучения результатов студентов.

Модуль заданий. Обеспечивает отображение практических задач и отправку решений.

AI Evaluation Engine. Предусматривает анализ ответов студентов, формирование оценок и персонализированной обратной связи.

Skill Passport. Отображает профиль компетенций студента на основе результатов выполнения заданий.

Дополнительные модули. Курсы, XP, истории выпускников и инструменты коммуникации.

Логика работы платформы
Работодатель создаёт практическое задание. Студент выбирает его и отправляет решение. При доступности ИИ-сервиса система анализирует ответ, формирует оценки и рекомендации. Полученные результаты используются для формирования профиля компетенций Skill Passport.

Работодатель может изучать результаты студента и использовать их как дополнительную информацию при оценке кандидата.

Важно: наличие соответствующих модулей в интерфейсе не означает, что все серверные функции уже развёрнуты и протестированы.
3. Инструкция по локальному запуску
Шаг 1. Подготовка файлов
Скачайте исходный код Skillora AI и поместите его в отдельную папку.

Структура проекта:
Skillora-AI/
└── skillora-live.html
Шаг 2. Запуск сайта
Для быстрого запуска дважды нажмите на файл skillora-live.html. Сайт откроется в браузере.

Для запуска через локальный сервер откройте терминал в папке проекта и выполните:
python -m http.server 8000
Шаг 3. Открытие в браузере
Перейдите по адресу:
html-to-url-1acf05.netlify.app
После загрузки откроется интерфейс Skillora AI.
Шаг 4. Использование демонстрационной версии
При отсутствии конфигурации Supabase приложение автоматически запускается в демонстрационном режиме с тестовыми данными.

Пользователь может ознакомиться с интерфейсом, разделами студентов и работодателей, каталогом заданий, Skill Passport и другими элементами платформы.
Шаг 5. Настройка серверного режима
В исходном HTML-файле присутствует конфигурация:
var CFG = window.SKILLORA_CONFIG ||
  { url: "", key: "" },
  DEMO = !CFG.url;
  Для подключения Supabase необходимо указать URL проекта и публичный ключ, подготовить структуру PostgreSQL, настроить авторизацию и политики доступа, а также развернуть функцию grade для ИИ-оценивания.

В обычном браузере window.claude автоматически не предоставляется, поэтому доступность ИИ-функций зависит от настройки интеграции.
Шаг 6. Остановка сервера
Чтобы остановить локальный сервер, нажмите Ctrl + C в терминале.
4. Технические особенности MVP
Исходный проект использует демонстрационный режим для показа пользовательских сценариев без обязательного подключения серверной инфраструктуры.

Интерфейс и локальные данные доступны непосредственно через HTML-файл. Для полноценной многопользовательской работы, синхронизации данных, ИИ-проверки и видеосвязи необходимо настроить соответствующие внешние сервисы.
5. Заключение
Skillora AI — веб-платформа, объединяющая практические задания, интеллектуальное оценивание и цифровой профиль компетенций студента.

Текущая архитектура позволяет демонстрировать пользовательские сценарии в локальном режиме и предусматривает дальнейшее подключение серверной инфраструктуры Supabase, PostgreSQL и ИИ-модели.

Для запуска демонстрационного интерфейса достаточно HTML-файла и современного браузера.
